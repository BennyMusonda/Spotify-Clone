# Spotify Clone
This project is a clone of Spotify. It is built for education purpose only. It is not for commercial use.

##View Live Website [Here]("https://bennymusonda.github.io/spotifyclone/")

## Features
1. User interface inspired by Spotify
2. Play, pause, and skip music tracks
3. Browse playlists and albums
4. Responsive design for screens

## Tech Stack
HTML and CSS
JavaScript
React

## Setup Instructions
Clone the repository to your computer.
Run npm install to get the tools.
Run npm start to open the app in your browser.
